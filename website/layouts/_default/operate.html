How we operate · demo for the {{ $site.event }}

One room per job, one agent per room.

{{ $site.orgName }} is a made-up nonprofit with seven staff roles, all played by one operator, Alex. It runs as a private server on Roomcord. Each staff process has its own room, and each room has a specialist AI agent. Agents draft, count and route. Alex approves every merge, outbound message and funder submission.

The rooms.

Each room holds one staff process and its agent. The public forms portal and the website feed the rooms. The People CRM holds every record once.
